Overview

What is the RepoLens MCP?

The Model Context Protocol (MCP) is an open standard that allows AI assistants to safely call local tools and query domain-specific engines.

terminal

100% Local Stdio

The JAR runs directly on your computer via standard input/output. No web service to host, no daemon process, and no exposed listening ports.

fact_check

Deterministic Scoring

Scores come from our 100-point rule engine, not AI guesswork. Your LLM receives structured, verifiable data it can reason about with confidence.

auto_fix_high

Greedy Set Cover Plans

Ask your assistant how to improve repository hygiene. RepoLens calculates the minimal set of remediation actions to maximize score recovery.

shield

Privacy First

Inspects public GitHub API metadata only. Never clones repository sources, never uploads tokens, and never sends telemetry to outside servers.

Privacy and Safety Guarantees

Strict local sandboxing & security standards

Zero Listening Sockets

The MCP server communicates exclusively across child process standard I/O (stdin/stdout). It does not bind to localhost or open any listening network ports.

No Source Code Clones

RepoLens only inspects public metadata endpoints via official GitHub REST APIs. Private repositories are never touched and your local codebase is never uploaded.

Token Confidentiality

Your optional GitHub Personal Access Token is passed directly to the local subprocess as an environment variable. It is never logged, stored on disk, or sent to RepoLens servers.

Pure Read-Only Access

All operations are read-only HTTP GET queries. RepoLens MCP will never create, mutate, or delete issues, branches, files, or repositories on GitHub.

Troubleshooting

Solutions for common configuration and runtime issues:

error_outline Java not found (command not found / exit code 127)
expand_more

Cause: Your client cannot locate the java executable in its execution environment PATH.

Fix: Replace "command": "java" with the full absolute path to your Java 17 binary:

  • macOS (Homebrew): /opt/homebrew/opt/openjdk@17/bin/java
  • macOS (Standard): /usr/bin/java
  • Windows: C:\\Program Files\\Java\\jdk-17\\bin\\java.exe
  • Linux: /usr/bin/java
refresh Tools not appearing in assistant after restart
expand_more

Cause: Either the configuration file has a trailing comma / JSON parse error, or the client was not fully quit.

Fix:

  1. Validate your JSON syntax in a linter (check for missing braces or dangling commas).
  2. Completely quit the client process (on macOS, press Cmd + Q; on Windows, ensure the background tray process exits).
  3. Verify the file path exists: run ls -la /path/to/repolens-mcp.jar in your terminal.
code Developer Rule: Nothing printed to stdout
expand_more

Critical MCP Protocol Rule: MCP stdio transport requires that stdout be strictly and exclusively reserved for JSON-RPC messages.

If you are developing or customizing the JAR:

  • Never call System.out.println() or write log statements to stdout. Even a single banner line will corrupt the JSON-RPC framing and crash the client parser.
  • Direct all diagnostics and logs to System.err (stderr) or a rolling file logger. MCP clients safely display stderr in their developer debug logs.
speed Rate limit reached (HTTP 403 API rate limit exceeded)
expand_more

Cause: GitHub allows only 60 unauthenticated requests per hour per IP. Analyzing large profiles quickly exhausts this quota.

Fix: Create a GitHub Personal Access Token (classic or fine-grained with public read permission) at github.com/settings/tokens and add it to your client's config under "env": { "GITHUB_TOKEN": "ghp_..." } to unlock 5,000 requests/hour.

vpn_key_off Expired or invalid token (HTTP 401 Bad credentials)
expand_more

Cause: The configured token has expired, been revoked, or contains accidental surrounding whitespace or quotation marks.

Fix: Regenerate your token on GitHub, paste the fresh token into your client configuration file, and restart your IDE.
